A lot of subtitle files' timeline may differ from the original video. This ultra lightweight tool can fix such issues.
How to use it : 


* Copy and paste your sub file (.srt) into the "srt-file" folder.
* Rename the pasted sub file as "subfix.srt" [No need to change the extension].
* Run subfix.exe in main directory, and put your desired delay or advancement of appearance of subtitles in miliseconds(ms). Add sign.
* (-) means subtitles will appear earlier, (+) means subtitle will appear later.
* The file will be fixed.
* Delete all files in input-srt-file directory after finished
